# Connections — object filter

Prototype of the connection **Edit connection → Select databases and schemas** step:
a database / schema tree plus an optional **object name** filter (match mode + chip
input) that is applied to the objects loaded in the next step, and the
**database-deselection warning** modal.

Built with Vite + React and the Radiant design system.

## Develop

    npm install
    npm run dev

## Build

    npm run build

Deploys on Vercel as a static Vite app (build output: `dist`).
